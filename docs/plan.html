🔬 Technology Stack Deep Dive

Detailed explanations of why each technology was chosen

🐍 FastAPI

Modern, fast (high-performance) web framework for building APIs with Python 3.10+ based on standard Python type hints. Automatic interactive documentation, async support, and dependency injection.

🧩 LangChain

Framework for developing applications powered by language models. Provides chains, agents, memory components. Industry standard for building LLM applications.

🔁 LangGraph

Extend LangChain with graphs. Cyclic behavior, stateful apps. Enable complex multi-turn conversations with proper memory management and handoff logic.

🚪 LiteLLM

Unified interface to call all LLMs. Standardize on one interface (like OpenAI) while supporting OpenAI, Anthropic, Cohere, Ollama, and hundreds more models.

🔍 FAISS

Facebook AI Similarity Search - efficient library for similarity search and clustering of dense vectors. File-based, zero setup, ideal for POC phase.

🗄️ Qdrant

Cloud-native vector database. Multi-tenant support, metadata filtering, clustering, managed service options. Production-ready for scaling.

💾 SQLite

Embedded database, zero configuration. Single file, no server process. Perfect for development, testing, and on-prem deployments.

🦈 PostgreSQL

Advanced relational database with JSONB, full-text search, row-level security. Production-grade for multi-tenant scenarios with proper tenant isolation.

⚡ Redis

In-memory data structure store. Caching, session storage, message queues. Sub-millisecond access, persistence options, pub/sub.

🔧 Celery

Distributed task queue. Handle long-running crawls, persistent tasks across restarts, worker scaling. Production workhorse for async jobs.

🎯 Phase 1: Proof-of-Concept (POC) IN PROGRESS

Duration: 3 months
Timeline: Month 1-3
Goal: Validate core AI capabilities
Team: 2-3 developers

🎉 Success Criteria

  • ✅ Chatbot responds intelligently using RAG from uploaded FAQs
  • ✅ Can call at least 2 custom tools (e.g., check_inventory, track_order)
  • ✅ Zalo Official Account integration working end-to-end
  • ✅ Docker Compose brings up full stack in < 2 minutes
  • ✅ Admin can upload knowledge via basic UI

Epic 1.1: Core AI Engine & RAG POC

  • Setup LangChain + LangGraph project structure
  • Integrate LiteLLM gateway (OpenAI/OpenRouter support)
  • Implement embedding pipeline (all-MiniLM-L6-v2)
  • Setup FAISS vector store per tenant
  • Build RAG retrieval chain (semantic search + context injection)
  • Implement conversation memory (last 10 exchanges)
  • Create LangGraph agent for multi-turn dialog

🔗 Dependencies:

None (foundational epic)

Epic 1.2: FastAPI Backend Foundation POC

  • Setup FastAPI project with async SQLite (aiosqlite)
  • Create tenant, user, conversation models (SQLAlchemy)
  • Implement JWT authentication & RBAC middleware
  • Build /chat/messages endpoint (WebSocket + REST)
  • Create /knowledge/upload endpoint (text, PDF, CSV)
  • Add rate limiting (aiolimiter, per tenant)
  • Implement /health and /metrics endpoints
  • Add structured logging (loguru or structlog)

🔗 Dependencies:

Requires Epic 1.1 for AI engine integration

Epic 1.3: Function Calling Framework POC

  • Design tool definition schema (JSON Schema based)
  • Create /tools/define endpoint (admin only)
  • Implement LangChain tool wrapper for custom endpoints
  • Build parameter extraction loop (chatbot asks for missing params)
  • Create 3 example tools: check_inventory, track_order, book_tour
  • Add tool call logging and error handling

🔗 Dependencies:

Requires Epic 1.1 (LangGraph agent), Epic 1.2 (backend endpoints)

Epic 1.4: Zalo Official Account Integration POC

  • Register Zalo OA developer account & create test OA
  • Implement webhook receiver (/webhooks/zalo)
  • Add webhook signature verification (HMAC-SHA256)
  • Build message parser (text, image, audio)
  • Implement message sender (Zalo API client)
  • Add template message support (for notifications)
  • Test end-to-end flow (user → Zalo → bot → response)

🔗 Dependencies:

Requires Epic 1.2 (backend), Epic 1.1 (AI engine)

Epic 1.5: Admin Dashboard (POC Version) POC

  • Setup React + Vite + Bootstrap 5 project
  • Build login page (JWT authentication)
  • Create knowledge upload form (file upload + text paste)
  • Build tool definition UI (name, description, schema, endpoint)
  • Add conversation viewer (simple list + details)
  • Implement basic analytics (queries/day, response time)

🔗 Dependencies:

Requires Epic 1.2 (backend API)

Epic 1.6: Docker & Deployment (POC) POC

  • Create Dockerfile for backend (multi-stage build)
  • Create Dockerfile for frontend (Nginx serve)
  • Write docker-compose.yml (backend, frontend, volumes)
  • Add .env.example with all required variables
  • Create Makefile (targets: dev, build, test, docker-up)
  • Write deployment guide (docs/deployment/docker.html)

⚠️ POC Risks & Mitigation

  • LLM API costs: Use GPT-4o-mini (cheapest), implement prompt caching, set spending alerts
  • Zalo API limits: Zalo OA has rate limits; implement request queuing and backoff
  • Vector search quality: Use smaller chunk sizes (200-300 tokens), test various embeddings
  • Tool calling errors: Extensive error handling, retry logic, fallback to chat-only mode

  • Add Prometheus metrics exporter

  • Add automated backups (DB + FAISS indexes)
  • Setup CI/CD pipeline (GitHub Actions or GitLab CI)

  • Create systemd unit files (backend, crawler, admin)
  • Build .deb package using fpm (for Ubuntu/Debian)

  • Add upgrade/migration scripts

  • Create security testing suite (OWASP Top 10)

  • Database migration complexity: Use Alembic for migrations, test thoroughly in staging

  • Performance at scale: Load testing early, implement caching aggressively

📚 Technical Glossary

Definitions of key technical terms used in this project

RAG (Retrieval-Augmented Generation)

A framework that enables LLMs to access external knowledge sources. The system retrieves relevant documents and provides them as context for the model to generate accurate, fact-based responses.

LangChain

An open-source framework for developing applications powered by language models. Provides building blocks for chains, agents, and memory.

LangGraph

An extension to LangChain that enables creating stateful, multi-actor applications with cyclic behavior. Essential for conversation memory and agent workflows.

FAISS (Facebook AI Similarity Search)

A library for efficient similarity search and clustering of dense vectors. Ideal for POC with small-scale deployments.

Qdrant

A cloud-native vector similarity engine optimized for low latency and high throughput. Supports filtering, metadata storage, and clustering.

MCP (Model Context Protocol)

An open protocol for connecting AI models to external tools and data sources. Enables standardized integration with third-party services.

Vector Database

A database that stores and queries data in vector format (embeddings). Enables semantic search based on meaning rather than exact keyword matching.

Embeddings

Numerical representations of text that capture semantic meaning. Similar texts have similar vector representations, enabling similarity search.

Function Calling

A capability where LLMs can identify when to call external functions/tools and what parameters to pass. Enables automation of complex workflows.

Multi-Tenancy

Architecture pattern where a single instance serves multiple customers (tenants), with data logically isolated per tenant.

Webhook

Callback mechanism where the server pushes data to a client URL when an event occurs. Enables real-time event-driven architecture.

Docker Compose

Tool for defining and running multi-container applications. Simplifies development and testing with single-file configuration.

Rate Limiting

Mechanism to restrict API request frequency. Protects against abuse and manages resource allocation fairly.

Token Bucket Algorithm

Rate limiting strategy where requests consume tokens from a bucket that refills over time. Smoothes traffic bursts.

Celery

Distributed task queue based on Python, message passing, and worker processes. Handles long-running tasks asynchronously.

Redis

In-memory data structure store used for caching, session storage, and message queues. Provides sub-millisecond access.

PostgreSQL

Advanced relational database with JSONB support, full-text search, and row-level security. Production-ready for multi-tenant scenarios.

SQLAlchemy

Python SQL toolkit and ORM. Provides database abstraction, migrations (Alembic), and connection pooling.

FastAPI

Modern web framework for building APIs with Python. Provides automatic docs, async support, and type hints.

React

JavaScript library for building user interfaces. Virtual DOM, component-based, and declarative.

Vite

Next-generation frontend tooling. Provides instant server start, HMR, and optimized builds.
