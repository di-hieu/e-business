Authentication & Authorization

JWT Authentication

The system uses JSON Web Tokens (JWT) for stateless authentication:

  • Access Token: Short-lived (15 minutes), used for API requests
  • Refresh Token: Long-lived (7 days), used to get new access tokens
  • Role-based Access Control (RBAC): Super Admin, Tenant Admin, Agent roles

Token Structure

# JWT Payload Example
{
  "sub": "user_12345",
  "tenant_id": "tenant_abc",
  "role": "tenant_admin",
  "permissions": [
    "knowledge:read",
    "knowledge:write",
    "tools:manage",
    "analytics:view"
  ],
  "exp": 1715683200,
  "iat": 1715679600
}

API Security

Rate Limiting

Protect against abuse with rate limiting:

  • Standard API: 100 requests/minute per tenant
  • Authentication endpoint: 10 attempts/hour (prevents brute force)
  • Rate limit headers: X-RateLimit-Limit, X-RateLimit-Remaining, Retry-After

Rate Limit Implementation

# FastAPI rate limiting example
from aiolimiter import AsyncTokenBucket
from fastapi import Request, HTTPException
from functools import wraps

# Token bucket limiter
rate_limiter = AsyncTokenBucket(100, 1)  # 100/min

async def rate_limit_middleware(request: Request):
    """Rate limit middleware for FastAPI."""
    async with rate_limiter:
        return await call_next(request)
