Zalo Official Account Integration

Zalo is Vietnam's leading messaging app with 200M+ monthly active users. The Zalo Official Account (OA) API enables businesses to send messages, create chatbots, and manage customer interactions.

Zalo Account Setup

  1. Register Zalo OA Developer Account: Visit https://open.zalo.me
  2. Create Official Account: Fill in business information
  3. Configure Webhooks: Set up callback URL for message receipts
  4. Get API Credentials: Client ID, Secret, Signature Key

Webhook Signature Verification

# Verify Zalo webhook signature
import hmac
import hashlib
import base64

def verify_zalo_signature(payload: str, signature_key: str, signature_header: str):
    """Verify Zalo webhook signature."""
    # Get signature from header
    received_signature = signature_header.split(' ')[-1] if signature_header else ""
    
    # Compute expected signature
    message = payload + signature_key
    expected_signature = base64.b64encode(
        hashlib.sha256(message.encode()).digest()
    ).decode()
    
    # Compare signatures
    return hmac.compare_digest(expected_signature, received_signature)

# Use in webhook endpoint
@app.post("/webhooks/zalo")
async def zalo_webhook(
    body: str,
    signature_key: str = Depends(get_zalo_signature_key),
    x_zalo_signature: str = Header(...)
):
    if not verify_zalo_signature(body, signature_key, x_zalo_signature):
        raise HTTPException(status_code=401, detail="Invalid signature")
    
    return {"status": "received"}

Facebook Webhook Verification

# Verify Facebook webhook signature
import hmac
import hashlib

def verify_facebook_signature(hub_signature: str, timestamp: str, body: str, verify_token: str):
    """Verify Facebook webhook signature."""
    # Create expected signature
    hmac_input = f"{timestamp}\n{body}".encode('utf-8')
    expected_signature = hmac.new(
        verify_token.encode('utf-8'),
        hmac_input,
        hashlib.sha256
    ).hexdigest()
    
    # Compare signatures (Facebook uses lowercase comparison)
    return hmac.compare_digest(
        hub_signature.lower(),
        expected_signature.lower()
    )

# Use in webhook endpoint
@app.post("/webhooks/facebook")
async def facebook_webhook(
    body: str,
    verify_token: str = Depends(get_verify_token),
    x_hub_signature: str = Header(...),
    x_hub_signature_timestamp: str = Header(...)
):
    if not verify_facebook_signature(
        x_hub_signature,
        x_hub_signature_timestamp,
        body,
        verify_token
    ):
        raise HTTPException(status_code=401, detail="Invalid signature")
    
    return {"hub.mode": "subscribe", "challenge": ...}

Instagram Direct Integration

Instagram Direct (now Instagram DMs) is available through the Facebook Graph API. Requires Instagram Business account and Facebook Page connection.

Instagram Setup

  1. Convert to Business Account: Instagram > Settings > Account > Switch to Professional
  2. Connect to Facebook Page: Business account must be linked to a Facebook Page
  3. Create Facebook App: Add Instagram Basic Display product
  4. Get User Tokens: OAuth flow for individual accounts

Instagram Business Requirements

  • Business Account: Not personal account
  • Page Access: Facebook Page linked to Instagram
  • Reviews: Instagram may review your account before enabling messaging

Instagram API Endpoints

# Get Instagram user ID from username
GET https://graph.facebook.com/v18.0/{app-id}/instagram-user-access-tokens \
  -H "Authorization: Bearer APP_ACCESS_TOKEN"

# Send message (using Page Token)
curl -X POST https://graph.facebook.com/v18.0/{instagram-user-id}/messages \
  -H "Authorization: Bearer PAGE_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "recipient": {
      "id": {instagram-user-id}
    },
    "message": {
      "text": "Hello from Instagram!"
    }
  }'
⚠️ Limitations: Instagram has stricter messaging rules. Cold messages (to people who haven't interacted) are limited to 24 hours per day. Focus on responding to incoming messages first.

Shared Message Processing

Regardless of the channel, messages flow through the same processing pipeline:

1
Webhook Received

Channel webhook endpoint receives payload (Zalo, Facebook, or Instagram)

2
Signature Verification

Verify webhook signature for security

3
Parse & Store

Extract message data, store in database, create conversation record

4
LLM Processing

Send to LangChain agent, RAG retrieval, tool execution

5
Generate Response

LLM generates text response, format for channel

6
Send via Channel

Call channel-specific API (Zalo, FB Messenger, Instagram)

Webhook Receiver Implementation

# Unified webhook handler
from abc import ABC, abstractmethod
import aiohttp
from typing import Any

class WebhookHandler(ABC):
    async def handle(self, body: str, headers: dict) -> dict:
        # Verify signature
        signature_verified = self.verify_signature(body, headers)
        if not signature_verified:
            raise HTTPException(status_code=401, detail="Invalid signature")
        
        # Parse payload
        payload = self.parse_payload(body)
        
        # Store conversation
        await self.store_message(payload)
        
        # Process with LLM
        response = await self.process_with_llm(payload)
        
        # Send response via channel adapter
        await self.send_response(payload["user_id"], response)
        
        return {"status": "received"}

# Zalo webhook handler
class ZaloWebhookHandler(WebhookHandler):
    async def verify_signature(self, body: str, headers: dict) -> bool:
        signature_key = self.get_signature_key()
        signature = headers.get("X-Zalo-Signature")
        expected = hashlib.sha256((body + signature_key).encode()).hexdigest()
        return hmac.compare_digest(expected, signature)

class FacebookWebhookHandler(WebhookHandler):

Rate Limiting & Quotas

Zalo OA Limits

  • Message limit: 2 messages/day to new users (must reply first)
  • Template limits: 100 templates/minute, 1000/day
  • Webhook calls: 100/second

Facebook Messenger Limits

  • Send API: 1000/second (burst), 300/s average
  • Webhook: 100/second
  • Templates: 1000/day per page

Instagram Limits

  • Message limit: 24 messages/day to non-followers
  • Spam detection: Instagram may limit suspicious accounts

Implementing Rate Limiting

# Rate limiter decorator
from aiolimiter import AsyncTokenBucket

class RateLimitedChannel:
    def __init__(self, channel_adapter: ChannelAdapter, rpm: int = 1000):
        self.adapter = channel_adapter
        self.limiter = AsyncTokenBucket(rpm, 1)
    
    async def send_rate_limited(self, user_id: str, content: dict) -> dict:
        async with self.limiter:
            return await self.adapter.send_message(user_id, content)

Error Handling

Channel-Specific Errors

# Handle send errors
async def send_with_retry(user_id: str, content: dict, max_retries: int = 3):
    for attempt in range(max_retries):
        try:
            response = await channel_adapter.send_message(user_id, content)
            return response
        except Exception as e:
            if attempt < max_retries - 1:
                wait_time = 2 ** attempt
                await asyncio.sleep(wait_time)
                continue
            
            # Log error, alert admin
            await log_error(f"Failed to send to {user_id}: {e}")
            
            # Fallback: send plain text
            return await channel_adapter.send_message(
                user_id,
                {"text": "Sorry, there was an error processing your request."}
            )

Message Failure Handling

  1. Log the error with context (user_id, message_type, error)
  2. Alert admin if error rate exceeds threshold
  3. Queue failed messages for retry
  4. Notify user if message fails repeatedly
