🚀 Getting Started with SC Chatbot

← Back to Documentation

Overview

Welcome to SC Chatbot - a production-ready, multi-tenant AI chatbot platform for SMEs. This guide will help you set up and run the platform locally for development and testing.

POC Ready

System Requirements

Hardware

  • RAM: Minimum 4GB (8GB recommended)
  • CPU: 2+ cores (4+ recommended)
  • Disk: 10GB free space (SSD recommended)

Software

  • Python: 3.11 or higher
  • Docker: Engine 20.10+ and Compose v2+
  • Git: Version control for cloning repository
  • npm/node.js: 18+ (for frontend development)

Installation Steps

Step 1: Clone the Repository

# Clone the repository
git clone https://github.com/di-hieu/e-business.git
cd e-business

# Install Python dependencies
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Install frontend dependencies
cd src/frontend
npm install
cd ../..

Step 2: Configure Environment

# Copy environment template
cp .env.example .env

# Edit environment variables
nano .env
# or
vim .env
# or
code .env

Required Environment Variables

# LLM API Configuration
OPENAI_API_KEY=your_openai_api_key_here
LITELLM_MODELS=gpt-4o-mini,gpt-4o

# Optional: OpenRouter for multi-provider support
OPEN_ROUTER_API_KEY=your_openrouter_api_key_here

# Database Configuration
DATABASE_URL=sqlite:///./data/chatbot.db
FAISS_DIR=/app/data/faiss

# Application Settings
LOG_LEVEL=INFO
MAX_CONCURRENT_MESSAGES=100
WEBSOCKET_HEARTBEAT_INTERVAL=30

# Zalo OA Configuration (leave empty for now)
ZALO_CLIENT_ID=
ZALO_CLIENT_SECRET=
ZALO_SIGNATURE_KEY=

# Facebook Configuration
FACEBOOK_APP_ID=
FACEBOOK_APP_SECRET=
💡 Tip: Get your OpenAI API key from https://platform.openai.com/api-keys. For POC testing, you can use OpenRouter which supports multiple LLM providers at competitive pricing.

Starting the Application

Using Docker Compose

# Build and start all services
docker compose up -d --build

# View logs
docker compose logs -f backend

# Stop containers
docker compose down

# Restart specific service
docker compose up -d backend

# Run backend in foreground (for debugging)
docker compose up backend

Access Points

  • Backend API (Swagger UI): http://localhost:8000/docs
  • Frontend Application: http://localhost:3000
  • Health Check: http://localhost:8000/health
⚠️ Note: The backend needs an API key configured before it can process requests. Start the backend with docker compose up to initialize the SQLite database and set up basic endpoints.

Manual Local Setup (Without Docker)

For Development with Python Debugger

# Activate virtual environment
source venv/bin/activate

# Run backend with Uvicorn
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# Run frontend development server
cd src/frontend
npm run dev

# Run tests
pytest src/backend/tests

Testing the API

# Health check
curl http://localhost:8000/health

# Chat endpoint (test with a sample message)
curl -X POST "http://localhost:8000/chat/messages" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"messages": [{"role": "user", "content": "Hello"}]}'

Understanding the Architecture

Component Overview

  • Backend API: FastAPI service handling WebSocket connections, REST APIs, and AI processing
  • Frontend: React application for admin dashboard and chat interface
  • SQLite Database: Stores conversations, users, and settings
  • FAISS: Vector store for RAG-based retrieval

Data Flow

User Message → WebSocket → Backend Router → LangChain Chain
                                                        ↓
                                               Vector DB (FAISS) → Retrieved Context
                                                        ↓
                                                      LLM → Response

Common Commands

# Development
docker compose up -d                    # Start all services
docker compose logs -f                  # Follow logs
docker compose exec backend bash        # Access backend container

# Testing
pytest src/backend/tests                # Run tests
pytest --cov=src/backend                # With coverage

# Database
docker compose exec backend sqlite3 data/chatbot.db

# Backend Debug
docker compose exec backend python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

Troubleshooting

Common Issues

Container Won't Start

# Check Docker logs
docker compose logs

# Check for errors
docker compose logs --tail=100

# Rebuild containers
docker compose down
docker compose up -d --build

Database Not Found

# Ensure data directory exists
mkdir -p data

# Check permissions
chmod -R 755 data

LLM Connection Failed

# Verify API key
echo $OPENAI_API_KEY

# Test API connection
curl https://api.openai.com/v1/models -H "Authorization: Bearer $OPENAI_API_KEY"
