System Architecture

SC Chatbot is a multi-tenant SaaS platform that provides AI-powered customer support chatbots for SMEs, with seamless integration into social commerce channels (Zalo, Facebook, Instagram).

Architecture Components

FastAPI Backend

Async WebSocket Server
Handles real-time message streams from Zalo/Facebook channels with low latency.
LangChain/LangGraph Agents
Orchestrate multi-turn conversations with conversation memory and tool calling.
MCP Server
Provides standardized API for external AI agents to query the chatbot.
Zalo/Facebook Channel Adapters
Pluggable adapters for different social media channels using adapter pattern.

Frontend Dashboard

React + Bootstrap 5
Admin dashboard for managing tenants, knowledge base, and tools.
React Context State
Simple state management for dashboard navigation and settings.

Storage Architecture

FAISS Vector Store
Per-tenant vector indexes stored as separate .faiss files for isolation.
SQLite Database
Single file database with tenant_id column for logical isolation.
