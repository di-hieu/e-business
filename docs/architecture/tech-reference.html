Backend Technologies

FastAPI

What is it?

Modern, fast (high-performance) web framework for building APIs with Python 3.10+ based on standard Python type hints.

Why use it?

  • Automatic documentation: Interactive Swagger UI and ReDoc endpoints generated from type hints
  • Async support: Native async/await for high-concurrency I/O operations
  • Fast: Uses Pydantic v2 for data validation with high performance
  • Type safety: Full type hints for better IDE support and fewer bugs
  • Development speed: Built-in dev server with hot reload

How it works?

SQLAlchemy

What is it?

Python SQL toolkit and ORM that supports asynchronous operations (aiosqlite).

Why use it?

  • Database abstraction: Write portable database code
  • Async support: Works with aiosqlite for concurrent requests
  • Migrations: Integrates with Alembic for schema versioning
  • Type hints: Full type hints from models

How it works?

# SQLAlchemy models
from sqlalchemy import Column, Integer, String, DateTime, ForeignKey
from sqlalchemy.orm import relationship, declarative_base
from aiosqlite import Connection

Base = declarative_base()

class Tenant(Base):
    __tablename__ = "tenants"
    
    id = Column(Integer, primary_key=True)
    name = Column(String(255), unique=True)
    api_key = Column(String(255), unique=True)
    created_at = Column(DateTime, default=datetime.utcnow)
    
    # Relationships
    conversations = relationship("Conversation", back_populates="tenant")

# Async database session
async def get_db():
    async with Connection("sqlite:///chatbot.db") as db:
        try:
            yield db
        finally:
            await db.close()

Pydantic

What is it?

Data validation using Python type hints. Used for request/response models.

Why use it?

  • Automatic validation: Validates all incoming data
  • Type safety: Catch errors at development time
  • Serialization: Convert objects to dictionaries
  • Integrates with FastAPI: Automatic docs from models

How it works?
