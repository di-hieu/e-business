Welcome to SC Chatbot

This tutorial will help you get started with the SC Chatbot platform. We'll walk through the basic setup steps: testing the API, adding knowledge, and configuring tools.

POC Ready

Prerequisites

Before you begin, make sure you have:

  • Docker installed (or use our Makefile)
  • Python 3.11+ for development
  • curl or HTTP client (Postman, Insomnia, etc.)
  • API credentials for your LLM provider (OpenAI, etc.)
  • Zalo Developer account for channel integration

Starting the Local Server

# Navigate to project directory
cd /home/dihieu/.ws/e-business

# Start with Docker Compose
docker-compose up -d

# Or start development mode
make dev

# Verify it's running
curl http://localhost:8000/health

# Expected response
{
    "status": "healthy",
    "timestamp": "2024-05-10T15:30:00Z",
    "version": "0.1.0"
}

Step 1: Test the Chatbot API

The chatbot is ready to receive messages. Let's test it with a simple greeting.

Send a Greeting Message

# Test basic chat endpoint
curl -X POST http://localhost:8000/chat/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "message": "Hello, I need help with my order",
    "channel": "web"
  }'

# Sample response
{
    "conversation_id": "conv_abc123",
    "response": "Hello! I'd be happy to help you with your order. Could you please provide your order number?",
    "tokens_used": 45,
    "tools_called": []
}

Understanding the Response

FieldDescription
conversation_idUnique ID for this conversation
responseLLM-generated response
tokens_usedToken count for billing
tools_calledList of tools used (empty for simple query)

Step 2: Add Knowledge Base

The chatbot needs knowledge to answer questions. Upload your FAQs, product manuals, or policy documents.

Upload Text Content

# Upload FAQ content directly
curl -X POST http://localhost:8000/knowledge/upload \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "tenant_id": "tenant123",
    "content": "Q: How do I return an item?\\nA: Returns are accepted within 30 days of delivery.\\n\\nQ: What is the warranty period?\\nA: All products come with a 1-year warranty.",
    "source": "manual-faq",
    "chunk_size": 200
  }'

# Response
{
    "document_id": "doc_faq_001",
    "status": "processing",
    "chunks_created": 12,
    "estimated_completion": "2024-05-10T15:32:00Z"
}

Upload PDF File

# Upload product manual
curl -X POST http://localhost:8000/knowledge/upload \
  -H "Content-Type: multipart/form-data" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@product-manual.pdf" \
  -F "source=product-catalog" \
  -F "chunk_size=300"

# Response
{
    "document_id": "doc_manual_001",
    "filename": "product-manual.pdf",
    "file_size": "2.5 MB",
    "status": "processing",
    "chunks_created": 85
}

Step 3: Configure Tools

Define custom tools that the chatbot can use to perform actions like checking inventory or tracking orders.

Define a Tool

# Define check_inventory tool
curl -X POST http://localhost:8000/tools/define \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer TENANT_ADMIN_TOKEN" \
  -d '{
    "tool_id": "check_inventory",
    "name": "check_inventory",
    "description": "Check product availability and pricing by region",
    "parameters": {
      "type": "object",
      "properties": {
        "sku": {
          "type": "string",
          "description": "Product SKU to check"
        },
        "region": {
          "type": "string",
          "enum": ["VN", "US", "EU", "APAC"],
          "description": "Target market region"
        }
      },
      "required": ["sku", "region"]
    },
    "endpoint": "https://oms.example.com/api/v1/inventory/check",
    "method": "GET",
    "auth_header": "X-API-Key",
    "auth_value": "{{OMS_API_KEY}}"
  }'

# Response
{
    "tool_id": "check_inventory",
    "name": "check_inventory",
    "status": "active",
    "created_at": "2024-05-10T15:35:00Z"
}

Define Track Order Tool

Step 4: Configure Zalo Integration (Optional)

If you want to use Zalo as a messaging channel, follow these steps:

Register Zalo Developer Account

  1. Visit https://open.zalo.me
  2. Fill in your business information
  3. Create a Zalo Official Account (OA)
  4. Get your API credentials (Client ID, Secret)

Setup Webhooks

# Register Zalo webhook
curl -X POST https://api.zalo.me/v2/webhook/register \
  -H "Authorization: Basic BASE64(CLIENT_ID:CLIENT_SECRET)" \
  -H "Content-Type: application/json" \
  -d '{
    "callback_url": "http://localhost:8000/webhooks/zalo",
    "subscribe": ["message.receive", "message.status"]
  }'

# Response
{
    "webhook_id": "wh_abc123",
    "callback_url": "http://localhost:8000/webhooks/zalo",
    "status": "active"
}

Configure in Admin Dashboard

  1. Go to Admin Dashboard
  2. Navigate to Settings → Channels
  3. Enable Zalo Official Account
  4. Enter API credentials
  5. Test connection
