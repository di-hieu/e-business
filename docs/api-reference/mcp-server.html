Overview

The Model Context Protocol (MCP) server enables external AI agents to query the SC Chatbot system. External agents can use MCP to interact with the chatbot, access knowledge, call tools, and receive responses.

Planned

What is MCP?

Model Context Protocol (MCP) is an open protocol designed to standardize how AI models connect to tools, data sources, and external systems. It provides:

  • Unified interface: All tools use the same JSON-RPC protocol
  • Language-agnostic: Works with Python, JavaScript, Go, Rust, etc.
  • Secure by default: API key authentication per tenant
  • Streaming support: Long responses can be streamed

Authentication

The MCP server uses tenant-specific API keys for authentication. Each tenant gets a unique key that must be included in the Authorization header.

Get MCP API Key

# Super admin creates MCP API key
curl -X POST http://localhost:8000/api/tenants/tenant123/mcp/api-key \
  -H "Authorization: Bearer TENANT_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{}'

# Response
{
    "api_key": "mcp_sk_abc123def456",
    "tenant_id": "tenant123",
    "name": "External Agent Integration",
    "expires_at": "2025-12-31T23:59:59Z",
    "permissions": ["query", "tools"]
}

Usage in API Headers

# Include API key in MCP requests
Authorization: Bearer mcp_sk_abc123def456

# Or use HTTP Basic Auth with tenant ID
Authorization: Basic dGVuYW50MTIzOm1jc19zaz8="
# (base64 encoded "tenant123:mcp_sk...")

MCP Protocol Details

MCP uses JSON-RPC 2.0 as its transport protocol. All requests follow this format:

JSON-RPC Request Structure

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "mcp/query",
  "params": {
    "tenant_id": "tenant123",
    "user_context": {...},
    "prompt": "..."
  }
}

JSON-RPC Response Structure

// Success
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "response": "..."
  }
}

// Error
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32000,
    "message": "Unauthorized",
    "data": "Invalid API key"
  }
}

Streaming Support (Experimental)

Long responses can be streamed using Server-Sent Events (SSE). This is useful for long RAG contexts or complex tool chains.

Implementation Example

FastAPI MCP Handler

# MCP Server implementation
from fastapi import FastAPI, Depends, HTTPException, Header
from pydantic import BaseModel
import os
from typing import Optional, List

app = FastAPI()

# MCP API keys (load from env)
MCP_API_KEYS = {
    "mcp_key_1": "tenant_abc",
    "mcp_key_2": "tenant_def"
}

# MCP Request models
class MCPQueryRequest(BaseModel):
    tenant_id: str
    user_context: dict
    prompt: str
    tools: List[str] = []
    stream: bool = False

@app.post("/mcp/query")
async def mcp_query(
    request: MCPQueryRequest,
    x_mcp_api_key: str = Header(None),
    x_forwarded_for: str = Header(None)
):
    # Verify API key
    if not x_mcp_api_key or x_mcp_api_key not in MCP_API_KEYS:
        raise HTTPException(status_code=401, detail="Invalid MCP API key")
    
    # Verify tenant matches
    expected_tenant = MCP_API_KEYS[x_mcp_api_key]
    if request.tenant_id != expected_tenant:
        raise HTTPException(status_code=403, detail="Tenant mismatch")
    
    # Check rate limits
    if not rate_limiter.check(request.tenant_id):
        raise HTTPException(status_code=429, detail="Rate limit exceeded")
    
    # Process query with LangChain
    result = await process_mcp_query(request)
    
    return result

async def process_mcp_query(request: MCPQueryRequest) -> dict:
    """Process MCP query using LangChain agent."""
    # Build prompt with context
    full_prompt = f"""
    User: {request.prompt}
    
    Available tools: {', '.join(request.tools)}
    
    Please answer using the appropriate tools if needed.
    """
    
    # Call LangChain agent
    from langchain.agents import initialize_agent, Tool
    from langchain.llms import LiteLLM
    
    llm = LiteLLM(model="gpt-4o-mini", api_key=os.getenv("OPENAI_API_KEY"))
    llm.agent = llm  # type: ignore
    
    # ... agent setup ...
    
    response = agent.run(full_prompt)
    
    return {
        "response": response,
        "tokens_used": 0,  # Calculate from LLM metrics
        "tools_called": []
    }

Security Considerations

Authentication

  • API Key Header: Include in every request
  • Tenant Validation: Verify tenant matches API key
  • IP Whitelist: Optionally restrict to known IPs

Rate Limiting

  • Prevent DoS attacks
  • Control LLM API costs
  • Ensure fair usage

Input Validation

  • Sanitize user prompts
  • Validate tool parameters
  • Block dangerous tool calls

# Python test script
import requests

def test_mcp_query():
    url = "http://localhost:8000/mcp/query"
    headers = {
        "Authorization": "Bearer mcp_sk_test",
        "Content-Type": "application/json"
    }
    
    payload = {
        "tenant_id": "tenant_test",
        "user_context": {
            "user_id": "test_user",
            "session_id": "test_session"
        },
        "prompt": "Help me track order ORD-999"
    }
    
    response = requests.post(url, json=payload, headers=headers)
    
    if response.status_code == 200:
        result = response.json()
        print(f"Response: {result['response']}")
        print(f"Tokens used: {result['tokens_used']}")
    else:
        print(f"Error: {response.status_code} - {response.text}")
